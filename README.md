# HTOO HTET | Travel Journal & Beyond

Discover Myanmar, one journey at a time.

## About the Project
This repository contains the source code for the official travel journal website of HTOO HTET. It shares travel stories, photo galleries, and culture updates from journeys across Myanmar, including documentary work in the Ayeyarwady Region.

## Features
- **Travel Stories:** Highlighting beautiful destinations across Myanmar.
- **Photo Gallery:** Capturing landscapes, people, and cultural moments.
- **YouTube Channel Integration:** Video journals and documentaries.

## Technologies Used
- HTML5 / CSS3 / JavaScript
- Jekyll (Static Site Generator)
- GitHub Pages (Hosting)
